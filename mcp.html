Connect your AI agents to FocusCaseX.
With permission, not luck.

FocusCaseX hosts its own MCP server. Any MCP-compatible agent — Claude Code, Cursor, a custom automation — can read your clinic notes, search the EMR and draft new pages. Nothing moves until you approve the connection and hand the agent a token you issued.

Why this exists

A clinic is busy. Let the agent do the running around.

Model Context Protocol (MCP) is an open standard that lets AI agents talk to real software. With MCP switched on, your agent can answer "what's on the book this morning", pull a patient's visit history into a letter, or draft a recall page — working directly against your workspace instead of you copy-pasting into a chat window.

Approval first, always An agent that connects without a token gets one answer: authorization required — and a pending request appears in your app. You approve it, or you don't. There is no other way in.
Scoped, read-mostly tools Agents can list, read, search and create notes, and browse the marketplace. No edits in place, no deletes, no settings — and every tool is documented right here.
Logged and revocable Every call — time, agent, tool, result — lands in the log. One tap revokes a token and the agent is out on its next request.
Your network, your data On-device MCP speaks only over your own LAN. On the web workspace, traffic flows between you and your agent — FocusCaseX never ships your records anywhere else.
How a connection is approved

Three steps. The clinic owner holds every key.

The agent asks

Any MCP client that connects without a valid token receives authorization required — and FocusCaseX records a pending request showing who asked.

You approve in the app

Open Settings → MCP & Automation, review the pending request, tap Approve. FocusCaseX issues a personal access token fcxmcp_… for that agent.

The agent connects

Paste the token into the agent's configuration (below). From then on every call is authenticated, logged, and revocable in the same screen.

Questions

Good to know

Is my patient data sent to some cloud AI?
No. MCP connects your agent to your workspace over your own connection. Whatever the agent does with what it reads is governed by the AI service you chose and its terms — FocusCaseX itself never forwards your records anywhere.
Can an agent change or delete my records?
No. The tool list is deliberately read-mostly: list, read, search, and create-only notes. There is no edit-in-place, no delete, and no access to settings or billing actions. Create never overwrites an existing note.
What happens if an agent connects without approval?
It gets a single "authorization required" response, and a pending request appears under Settings → MCP & Automation showing who asked. If you don't recognize it, tap Deny — and it stays locked out.
How do I switch MCP off?
Revoke the token. The agent is out on its next request — no restarts, no settings changes. On a device you can also simply stop the host server.
Which agents can connect?
Anything that speaks MCP over HTTP: Claude Code, Cursor, custom scripts, scheduling automations, in-clinic kiosk assistants. If it can POST JSON-RPC with a header, it can connect — once you approve it.
