FAQ — plain answers for clinics

The questions optometry clinics ask most, answered without jargon. The whole product is documented A to Z in the full guide — this page stays the quick path.

The basics
Do I need the internet?
No. FocusCaseX works offline — your records live on your device and every board, page and note opens without a connection. The one online moment is the licence check when a device first activates — the one-time sign-in that ties the device to your licence; after that one check-in the device is trusted — remembered, never asking for a code again — and the clinic runs without a connection. The web app at focuscasex.vercel.app opens as usual whenever you want it — it is one way in, not a requirement. And on a computer, the fcx command (a small helper program you run by typing) can open a workspace web page that the machine itself provides — a local page that needs no internet at all. See the local workspace page.
What is FocusCaseX, in one sentence?
A clinic workspace for eye care that works offline: register patients, run refraction and exam flows, manage optics, dispensing and billing, set recalls — all on your own device, with pages you can read and print.
What is an Extension?
A small add-on that adds one feature to the workspace — an extra panel, an automation, a quick reference one tap away. You install it from the marketplace (the built-in catalog of ready-made add-ons) in one tap and remove it just as easily. Browse what is available in the marketplace.
What is a WorkBench?
A whole clinic setup packed into one install — the boards (the ready-made working screens, like today's list and the patient files), the pages (plain documents you can read and print), a theme (a new look for every screen at once), templates (pre-written clinical notes and letters) and starter settings. Applying one configures the workspace in a single step, and switching between installed WorkBenches works like switching modes. Your records never move.
What happens to my setup when a WorkBench changes?
A WorkBench is the whole clinic setup — boards, pages, the look and the note formats — packed into one install. When you switch to a different one, the shape of the workspace changes with it: different boards greet the day, different starter pages exist, and the look follows the new WorkBench. Your records never move — patients, exams, notes and history stay exactly where they are — and switching back is one tap, because each installed WorkBench is a mode you change into and out of. More under WorkBenches.
What are capsules, themes, templates and snippets?
Capsules are ready-made working screens — short blocks you drop into any page that show live clinic information, like today's appointments or who is due back. Themes change the look of every surface at once. Templates are pre-written clinical notes and letters you fill in for the patient in front of you. Snippets are small interface tweaks, like bigger headings. All four install in one tap from the marketplace.
Can I keep notes the way my clinic already writes them?
Yes. Templates — pre-written clinical notes and letters — come with wording your clinic can adopt or replace, and every page in the workspace is plain text (markdown) you can read, edit and print, so a note keeps your clinic's own voice. Start from a template or from a blank page; either way the words stay yours. How pages and notes work is in the workspace tour.
How do I create my own Extension?
Follow the authoring guide — create your own Extension: two small files, one catalog entry, a local test with the fcx command, then a pull request to the marketplace (you send the finished Extension in to be listed). No build tools needed.
What is a board?
A board is one working screen of the workspace, with one job: Today is the day at a glance, Patients holds the patient files, Appointment is the booking book, and Dispensing, Billing and Recall each follow the same pattern. Boards sit in the sidebar, and the clinic day moves across them. Capsules — ready-made boards — can be dropped into any page, and the tour of the workspace walks every board in order.
Can I use it on my phone?
Yes. Phones and tablets run the Android app — the whole clinic in a pocket, fully offline: register a patient between rooms, run a refraction in the exam chair, take payment on the spot. It installs in three steps from the install guide, and add-ons come from the same catalog as everywhere else. More under phones and tablets.
Is the app the same on phone and computer?
The records-shaped parts are the same everywhere: register patients, run exams, take payment, set recalls — the same features on every device, under the same licence. What differs is the way in: there are three — the web workspace in a browser, the Android app on phones and tablets, and the fcx command on a computer. All three open the same clinic, and they are described under What is FocusCaseX.
What is a pack file?
A pack is a single file that carries one add-on — an Extension (a small feature add-on), a theme (a new look), a capsule (a ready-made working screen) or a WorkBench (a whole clinic setup). Because it is one file, it travels like any attachment: received by email or handed over on a USB stick, then installed in one step, straight from the file itself — no trip to the marketplace needed. The ending on the file tells you what is inside: .fcxext an Extension, .fcxtheme a theme, .fcxcapsule a capsule, .fcxwb a WorkBench. You see exactly what a pack holds before anything is applied. More under one-file packs.
What is the difference between a pack and the marketplace?
The marketplace is the built-in catalog of add-ons you browse inside FocusCaseX — see what an item adds and install it in one tap, with no files involved. A pack is the same kind of add-on bundled into a single file that arrives from outside — by email or on a USB stick — and installs straight from the file. Both routes install the same items, and both show exactly what is inside before anything is applied. More under one-file packs.
Do I need a technical person to set it up?
No. Setup is seven plain steps — open FocusCaseX, sign in, activate the device once (the one-time check-in with your FCX-XXXXXX code), register your first patient, run the day from the boards, add what your clinic needs, and let it update itself. Your licence email, password and code are the only paperwork involved. The full list is under start in seven steps.
Can I try it before my whole clinic moves over?
Yes — start with one device and one licence seat. A licence carries a device limit (two devices by default), so you can run FocusCaseX on a single phone or computer first, see how the clinic day feels, and grow one device at a time as the rest of the clinic moves over. The marketplace — the built-in catalog of add-ons — adds boards and extras whenever you need them. The start in seven steps page walks the first device.
Licences and devices
How do I put FocusCaseX on another computer in my clinic?
Install the fcx command — a small helper program you run by typing — with one line typed in a terminal window (the text window on a computer where commands are typed); the install guide has it. Then run fcx setup and sign in with your licence email and the FCX-XXXXXX code issued for that machine. Every device counts against the licence's device limit.
What is the FCX code my clinic owner gave me, and where do I type it?
It is the activation code for your licence — it looks like FCX-XXXXXX. In the app, a new device asks for it once at first launch, right after sign-in. On a computer, run fcx login in a terminal window and answer the three prompts. The licence flow, step by step: account and licence.
It says my code reached its device limit — what now?
Contact your clinic owner. They free a slot by revoking a device that is retired or lost — revoking switches that device off the licence — or raise the limit for your code; then the new device activates as normal.
I forgot my password — what now?
Ask your clinic owner — the password is reset on the licence. Nothing on your device changes, and your records stay exactly where they are.
Is my licence tied to one device? What is a trusted device?
The licence belongs to the clinic and carries a device limit — two devices by default. A trusted device is one that has activated once — activation is the one-time sign-in that ties it to your licence — and it is remembered from then on: it never asks for a code again. How activation works is described under security and privacy.
Can I move my licence to a new computer? And what happens if my device is lost or replaced?
Yes — and a lost or replaced device follows the same road, because both are handled by your clinic owner. They revoke the old or lost machine on the admin Devices page, which frees its slot and stops that machine from activating again, and a fresh FCX-XXXXXX code is issued for the new one, which then activates the normal way. If a device is lost, tell the owner straight away — nothing on the lost machine holds anything that helps anyone else sign in. The records on a retired machine stay right where they were. The whole move is described under security and privacy.
How do I remove FocusCaseX from a computer?
Run the installer with --uninstall — the command is removed. To free that machine's slot on the licence, ask your clinic owner to revoke it.
Can two clinics share one licence?
No. One licence is one clinic — codes are bound to a single email, and the devices under it share one workspace. A second clinic needs its own licence and its own email.
Your data
Does my patient data go anywhere?
No. Records live on your device. Activation and the periodic licence check send hardware identity only — never patient records. Export anything, any time, as plain files you keep.
Does installing an Extension touch my records?
Never. Installing or removing an Extension changes the setup only — your case files, documents and history stay exactly where they are.
What exactly works offline?
Everything you do day to day: patients, exams, notes, boards, recalls and every installed add-on. First activation on a new device — the one-time sign-in that ties it to your licence — needs a connection once; after that the device is trusted and the clinic runs without one. The first steps guide walks activation.
Can I get my records out?
Yes — always. Export writes your records as plain files that you keep: open them, print them or copy them anywhere, with or without FocusCaseX. Nothing is locked inside the app, and the full guide covers exporting step by step.
Where do my records live?
On your device — that is the point. The phone or computer you work on holds the records; no server holds a copy and nothing is sent away to be stored. That is why the clinic runs without the internet: the records are already where you are.
What if my phone or computer is lost?
Your records live on the device, so keep exports as you go — a recent export is your copy. To free the lost machine's slot, ask your clinic owner to revoke that device, and the next one activates as normal. The lost machine holds nothing that lets anyone else sign in. What activation protects is described under security and privacy.
Android and packs
How do I install the Android app?
The install guide links the latest build to download straight onto the device. Open the downloaded file, and when Android asks, allow the install — a one-time switch the system remembers. Then open FocusCaseX from your app list and sign in.
Does the Android app work offline?
Yes — everything day to day. Patients, exams, notes, boards and billing all live on the device and open without a connection. The one online moment is the licence check the first time the device activates — the one-time sign-in that ties it to your licence; after that it is trusted and the clinic runs without one.
How do I update it?
The app checks for updates on its own and tells you inside the app when one is ready — you confirm and it updates. There is no store page to visit and nothing to watch for.
What is a pack file on Android?
A single file that carries one add-on — an Extension (a small feature add-on), a theme, a template, any installable item. It arrives downloaded or received from another device, and the app loads it straight from the file itself: you open the file, a confirmation lists what it holds, one tap and it is in. How packs work: one-file packs.
Can a pack I receive by email work on both my phone and my computer?
Yes — one file, both devices. On a computer, fcx install reads the pack straight from the file, no network needed. On the phone, open the file and the app loads it the same way. Nothing is fetched from a catalog either way.
Can I move an add-on from my computer to my phone?
Yes. Send the pack file over — email, a shared clinic folder or a cable — then open it on the phone and load it straight from the file. The packs guide covers the format and the Android guide shows the flow.
Do add-ons change my records?
Never. Installing an add-on is setup only — panels, boards and settings are added, and your case files, documents and history stay exactly where they are. Removing one is the same: the setup changes, the records do not.
Updates and sharing
How do I update the app?
The Android app checks for updates on its own and tells you inside the app when one is ready — you confirm and it updates. The web workspace is always the current build; there is nothing to do.
How do I update the fcx command?
Run fcx update — when a newer build ships, it prints the one-line install command to run. Re-running the original install command works too, and fcx --version confirms the build afterwards. The care commands are covered in the CLI guide.
Can I share the app with the front desk over the clinic network?
Yes. When your clinic has its own network, fcx open and fcx serve can share across it — fcx open serves the workspace page itself and fcx serve shares the marketplace with every computer on it; each prints the address to open. With no clinic network, the web workspace opens as usual from anywhere.
How do I check everything is healthy?
Run fcx vitals. It prints a short list of checks, each marked OK or pointing at what needs attention, and the lines are written to be read by people. If something looks wrong, paste the list to whoever helps you — it usually points straight at the fix. More in care and diagnostics.
Does the workspace need the internet to run?
No. The fcx command serves the workspace page from the machine itself, so with no network at all the page still opens on that machine. On a clinic network the same page also answers on the network address, so other devices on it can open the page too. The internet is only needed the first time a device activates and for updates — see the local workspace.
How do I check which build I have?
On a computer, run fcx --version — it prints the build in one line, and fcx update says whether it is the current release. On Android, the app tells you inside the app when an update is ready, so you always know where you stand.
Contact
Who do I contact?
Your clinic owner for codes, device moves and password resets. For everything else, FocusCaseX support answers licence mail directly — the docs pages always point at the current contact.
